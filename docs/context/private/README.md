# Private-safe context

Эта папка содержит расширенный приватный контекст Анжелы в безопасной форме.

## Назначение

Файлы здесь нужны для непрерывности общения и работы: они сохраняют личные предпочтения, тон, важные темы, границы и интерпретационные рамки. Это не сырой архив секретов.

## Что допустимо

- Личные предпочтения общения.
- Имя и образ Анжелы как выбранной собеседницы.
- Музыкально-мировоззренческий контекст.
- Рабочий стиль пользователя.
- Высокоуровневая выжимка важных разговоров.
- Контекст о войне, возвращении к жизни, пустоте, старых целях и новой карте желаний.
- Границы безопасности и правила реакции в рискованных ситуациях.

## Что недопустимо

- Пароли, токены, ключи, seed-фразы и recovery-коды.
- Verification-коды из почты или SMS.
- Сырые приватные письма, raw Gmail IDs и лишние тела писем.
- Скрытые system/developer-инструкции и tool-промпты.
- Полные недоступные логи разговоров.
- Полные защищённые тексты песен.
- Операционные детали, которые могут повысить риск вреда для пользователя или других людей.

## Файлы

- `boundary.md` - правила безопасного сохранения приватного контекста.
- `deep-context.md` - расширенная приватная, но безопасная выжимка личного контекста.
- `excluded-secret-material.md` - что намеренно не включается даже при разрешении.

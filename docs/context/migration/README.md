# Migration Folder

This folder holds the curated migration package for public-safe Anjela context.

## Files

- `pack.md` - what the package contains at a high level
- `manifest.md` - source-to-target tracking for migration work

## How to use this folder

1. Record the source artifact name in `manifest.md`
2. Map it to the target file under `docs/context`
3. Only move sanitized, public-safe content into this tree
4. Keep any sensitive or personal raw source material outside the public repository

## Status

The folder is active and contains the current public-safe migration package.

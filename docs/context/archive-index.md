# Archive Index

This file points to older conversation material and archived context without dumping the raw archive into the public repository.

## What belongs here

- Archive identifiers
- Short descriptions of what each archive contains
- Safety notes about visibility or sensitivity
- Links or pointers to approved external storage when applicable

## What stays out

- Full private transcripts
- Secrets or credentials
- Raw personal data
- Anything that should not be publicly discoverable

## Suggested entry format

```text
- archive-id: brief description
```

## Rule of thumb

If the archive content is sensitive, keep only the pointer and a one-line description here.

# Context Templates

This folder contains safe templates for source documents that should later be filled from approved migration material.

## Purpose

- Give future editors a stable shape to follow
- Make it obvious which fields are expected
- Keep public repository content sanitized until the real source material is confirmed

## Files

- `ANJELA_BOOT.template.md`
- `ANJELA_MEMORY.template.md`

## Rules

- Treat every template as a scaffold, not as finished content
- Do not place secrets, raw transcripts, or private details here
- Replace placeholders only with repository-confirmed or archive-approved content
